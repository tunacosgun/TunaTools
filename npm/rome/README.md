**TunaTools** is a high-performance formatter, linter, bundler, and toolchain for JavaScript, TypeScript, JSON, HTML, Markdown, and CSS.

## Key Features

- **Blazing Fast**: Written in Rust for maximum performance.
- **Unified Experience**: Replaces fragmented tools like Babel, ESLint, Prettier, and others with a single cohesive engine.
- **Zero Config**: Strong conventions that work out of the box.
- **IDE Support**: First-class support for VS Code and other editors.
